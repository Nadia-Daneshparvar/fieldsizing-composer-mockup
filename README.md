# Field Sizing Composer mockup

Deterministic (no-AI) prototype of Arc Composer Field Sizing: one self-contained offline HTML file.

- `index-no-ai-claude.html` is the prototype (v0.5.1, 2026-10-07).
- `index.html` redirects to it for GitHub Pages.

v0.5.1 reflects the sizing SME review of 2026-10-05:
- specialty tabs throughout;
- read-only segmentation;
- forecast shares with an "adds to 100%" check;
- standard method defaults with no methodology options;
- forecast reallocation for Affordable Coverage and Response Curve;
- a scenario summary split into sizing assumptions and sizing outcomes.

All data shown is synthetic for demonstration purposes.
